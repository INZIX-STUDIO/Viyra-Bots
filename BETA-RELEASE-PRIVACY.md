# Proposed privacy wording for Viyra Beta 1.0

Replace the existing “Bring Your Own Keys (100% Local Privacy)” release bullet with:

> **Runs locally, with your choice of providers:** The Viyra desktop application runs entirely on your computer. Viyra requires external providers; when you use an external service, information may be sent to the provider you configured for that service. Whether that provider retains or shares information depends on its practices and policies. Review the provider’s terms and privacy policy.

This is a proposed replacement for the published release description. Merging this file does not update the GitHub release description; the approved wording must be applied separately.
